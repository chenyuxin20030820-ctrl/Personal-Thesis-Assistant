# 个人论文助手

本地运行的 Python 前后端一体应用。FastAPI 同时提供页面和接口；LangChain Agent 处理对话；MySQL 保存会话、消息及附件。

## GitHub 仓库与运行方式

此仓库存放网站源码、依赖和部署说明。GitHub Pages 只能托管静态文件，不能运行本项目的 FastAPI、MySQL 和后台任务；克隆仓库后按下文步骤在本机启动。若需公开访问的网站，还需要另选支持 Python 服务和持久化 MySQL 的运行平台。真实密钥只填在本机 `.env`，不要提交到仓库。

## 首次运行

1. 在项目根目录的 `.env` 中填写 `MYSQL_PASSWORD`、`DEEPSEEK_API_KEY` 和 `SERPAPI_API_KEY`。`OPENALEX_API_KEY` 可选，能提高 OpenAlex 的调用额度。AI 对话与文献精读均使用 DeepSeek `deepseek-flash`，显式关闭思考模式。密钥只保存在本地 `.env`，不会返回给浏览器。
2. 本机 MySQL 服务需运行，root 账号需有创建数据库及表的权限。服务首次启动会自动创建 `paper_assistant` 数据库与表。可通过 `MYSQL_DATABASE` 修改数据库名。
3. 安装并启动：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
   ```

4. 浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000) 进入首页；AI 对话位于 `/chat`。访问 `/api/health` 可查看数据库和模型配置状态。

## 已实现

- 首页：研究问题提交后进入 AI 对话，快捷卡片进入检索与精读，最近任务可跳转到检索、精读或对话详情；无真实任务时显示明确标注的演示记录
- AI 对话页三栏布局和空会话欢迎页
- 新建、切换、搜索、重命名、删除历史会话
- 多轮对话及 MySQL 持久化
- 上传 PDF、DOCX、TXT、PNG、JPG、WEBP；文档文本可供 Agent 查询，图片发送给支持视觉输入的模型
- AI 对话使用 DeepSeek Flash，显式关闭思考模式；Agent 只调用当前对话上传文件检索和本地日期工具，不执行联网搜索。系统提示词位于 `app/prompts/chat_system.txt`，修改后下一条消息即可生效。
- AI 回复支持 Markdown 渲染（标题、列表、引用、代码块、表格与安全链接）；原始文本仍保存在 MySQL，历史对话打开时同样渲染。原始 HTML 会转义，危险链接协议会被拒绝，图片语法只显示为可点击链接，不自动加载远程图片。
- 文献检索页：选择中文或英文文献，优先通过 OpenAlex API 按语言、年份检索；结果不足或 OpenAlex 失败时使用 SerpApi Google Scholar 补充。支持按主题、年份、数量和排序方式检索；结果每页展示 10 篇，支持跨页勾选、结果内搜索、查看来源与可用 PDF 链接、展开分析，以及导入主题文献库、Zotero 或发起单篇精读。真实检索结果仅有元数据与摘要；没有全文证据的研究目的、方法和实证过程明确标注无法判断。
- 文献库页 `/library`：包含全部文献、精读文献库和主题文献库。检索结果勾选后点“导入文献库”，可在弹窗选择已有主题或新建主题。精读任务获取到可提取文字的 PDF 后自动保存原文到精读文献库，任务完成后补入中文翻译和阅读报告；模型调用失败时，已获取的原文仍可在文献库查看。两类文献库均支持本地上传原文 PDF 和可选的中文版 PDF。详情展示摘要、DOI、来源链接、PDF、报告等可用信息；模拟记录明确标注不可正式引用。
- 文献精读页 `/reading`：上传真实 PDF，或输入 DOI、arXiv 链接、公开 HTTPS PDF 链接创建后台任务。DOI 先查 OpenAlex 开放获取 PDF；无法取得时使用 SerpApi Google Scholar 检索 PDF 候选，并验证与 DOI 对应及可下载性。取得原文后立即按论文标题命名并存入精读文献库。提取 PDF 可选文字后检测语言：英文论文逐段翻译、合并并生成以中文标题命名的中文版 PDF；中文论文跳过翻译。阅读报告 Agent 按原文顺序分批阅读，在应用上下文预算的 40% 阈值压缩事实记忆，并按创建任务时保存的用户模板字段生成中文报告。Excel、Word、Markdown 模板的可编辑字段会被填写；PDF 模板作为栏目参考生成新 PDF。未上传模板时提示用户先到设置页上传，不能创建精读任务。报告文件按论文标题加“阅读报告”命名，格式与模板一致。原文、中文版 PDF（仅英文论文）和报告均可在结果区查看或下载。
- 任务记录页 `/tasks`：汇总主动检索、文献精读和 AI 对话记录；支持搜索、筛选及跳转详情，精读任务可重试或删除。服务重启后恢复未完成的精读任务。精读页与任务页另展示 5 条明确标注的模拟任务，仅供界面体验，不写入数据库，也不提供真实 PDF、翻译或报告。
- 每次主动检索会把完整结果快照随检索任务保存到 MySQL；从任务记录打开检索任务时直接加载当时的列表和分页，不再次调用 SerpApi。旧版模拟任务会按原条件恢复；旧版 Google Scholar 任务已按原条件补存结果，并在页面标明属于补存结果。
- 设置页 `/settings`：保存个人信息、头像、检索数量、Zotero 目录名称和一份文献阅读报告模板。报告语言固定为中文。模板支持 Markdown、PDF、Word（.docx）与 Excel（.xlsx），最大 5 MB，可替换、下载或移除。新任务建立时保存模板原文件、文字与格式快照；Excel、Word、Markdown 的可编辑字段会被填充，PDF 根据模板内容生成新文档。通过本机 Zotero 10+ 的本地 API 授权连接；英文精读任务可归档原文、中文版和阅读报告 PDF，中文精读任务归档原文与阅读报告 PDF。重复导入按来源任务 ID 跳过已有条目。

文献检索页位于 `/search`，主检索接口为 `/api/search`。普通页面会自动恢复数据库中最新一次检索的条件与结果；带 `?task=<ID>` 的链接会显示指定历史任务的快照，不会重新请求检索 API。OpenAlex 按用户要求最多返回 100 篇，页面每页显示 10 篇；不足时通过 SerpApi 补充，后者每次请求最多 20 篇并消耗账户额度。中文/英文筛选主要依赖 OpenAlex 的元数据语言字段；该字段不保证全文语言。SerpApi 结果以检索语言参数和标题文字进一步筛选。旧任务中的模拟结果仍可从历史记录查看，但新检索不再生成模拟文献。

## Zotero 本地连接

1. 启动 Zotero 10+，在“设置 → 高级”启用“允许此计算机上的其他应用与 Zotero 通信”。
2. 打开 `/settings`，点击“连接 Zotero”，在 Zotero 授权弹窗选择“始终允许”。单次“允许”产生的密钥不足以完成批量条目和 PDF 附件写入。密钥仅保存在本地 MySQL，不发送给网页。
3. 在检索页勾选模拟文献后点击“导入 Zotero”；在真实精读任务完成后点击“归档至 Zotero 每周精读文献”。目标目录不存在时会自动创建。

Zotero 写入需由用户在 Zotero 弹窗中授权。当前开发环境已验证本地 API 可读取，但未在本次开发中触发授权弹窗或实际写入个人 Zotero 库。中文 PDF 生成依赖 `reportlab` 和系统中文字体；安装 `requirements.txt` 后即可使用，也可通过 `PDF_RENDER_PYTHON` 与 `PDF_CJK_FONT` 指定 Python 解释器和字体文件。

精读仅处理能提取文字的 PDF（默认最多 10 MB、300 页、100 万字符）；扫描件请先 OCR。DOI 获取失败时请上传你有权使用的文件；SerpApi 结果仅提供候选链接，不能保证每篇论文都有可获取的 PDF。精读结果依赖本地 MySQL 与 DeepSeek 密钥；缺少配置时会明确提示。填写 `.env` 后重启服务使配置生效。翻译 Agent 系统提示词位于 `app/prompts/translation_system.txt`，阅读报告 Agent 位于 `app/prompts/reading_report_system.txt`，修改后下一次任务调用即生效。`READING_CONTEXT_TOKENS`（默认 32000）设置报告 Agent 的应用工作窗口，达到其 40% 即触发压缩；这是应用的保守预算，并非 DeepSeek 模型官方上下文上限。

当前为单用户本地应用，没有账号系统。AI 对话所用模型需要支持 OpenAI 兼容的聊天接口与工具调用；图片理解还需要模型支持视觉输入。首页提问会带入 AI 对话，模型尚未配置时保留在输入框等待发送。文献检索需要 MySQL 和对 OpenAlex 的网络访问；SerpApi 兜底还需要有效的 `SERPAPI_API_KEY`。
